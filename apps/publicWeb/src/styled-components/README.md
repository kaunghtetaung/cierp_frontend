# Styled Components

## Purpose
Final presentation components that combine base-components and feature-components with complete styling.
These are the components you actually use in your pages and layouts.

## Usage
- Import these in your pages/layouts
- These wrap base-components and feature-components
- All styling and theming logic goes here
- Theme-specific implementations

## Examples
- StyledButton (Button + theme styling)
- StyledSearchBox (SearchBox + theme styling)
- StyledUserMenu (UserMenu + theme styling)
- Header/Footer (complete styled layouts)

## Rules
❌ Business logic (use feature-components)
❌ Bare functionality (use base-components)
✅ Complete styling
✅ Theme implementation
✅ Final UI presentation
✅ CSS classes and design
