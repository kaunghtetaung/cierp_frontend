# Feature Components

## Purpose
Business logic components that handle specific features and functionality.
These contain the core logic for your application features but minimal styling.

## Usage
- Import these for feature-specific functionality
- Combine with base-components for structure
- Wrap with styled-components for final presentation

## Examples
- SearchBox (search logic)
- UserMenu (user management)
- LanguageSelector (i18n logic)
- DataTable (data handling)

## Rules
❌ Heavy styling/CSS
❌ Pure UI components (use base-components)
✅ Business logic
✅ Feature functionality
✅ State management
✅ API interactions
