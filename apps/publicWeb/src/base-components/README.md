# Base Components

## Purpose
Pure functional UI components without any styling or CSS classes.
These are the building blocks that provide structure and basic functionality only.

## Usage
- Import these when you need raw functionality
- Apply styling through wrapper components in `styled-components`
- No CSS classes should be hardcoded here

## Examples
- Button (functional only)
- Input (structure only) 
- Modal (behavior only)
- Dropdown (logic only)
- Alert (custom implementation with semantic variants)

## Rules
❌ No CSS classes
❌ No styling logic
❌ No theme-specific code
✅ Pure functionality
✅ Accessible markup
✅ Event handling
